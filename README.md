# Autonomous HR Operations AI Agent (n8n)

An intelligent, conversational AI Agent built using **n8n**, **Groq LLM**, **Google Docs**, and **Gmail** that handles employee policy queries and automates leave applications.

## Capabilities
1. **Policy Knowledge Base (RAG):** Dynamically reads company policy documents from Google Docs to answer employee questions accurately.
2. **Conversational Memory:** Retains chat context across multi-turn interactions to gather missing details (employee name, leave dates).
3. **Autonomous Action:** Uses the Gmail tool to draft and dispatch formal leave application emails automatically.
